# 演示数据（全部虚构）

让工作台开箱就有完整效果的三步：

1. **导入台账**：工作台点「批量导入」→ 选本目录的 `演示台账.csv`
   （5 张虚构企业卡，跨 2023-2025 三个年份，覆盖文审/现场/孵化/培训/归档各形态）
2. **放报告与模式卡**：把 `演示报告-上海示例智能制造有限公司.md` 拷进 config
   「库.社会兼职.落点.资料评审库」对应目录，`演示模式卡-*.md` 拷进「质量模式库」目录
3. **自动关联**：台账点「批量关联报告」→ 报告按企业名自动挂到卡片「来源文件」

然后打开「上海示例智能制造有限公司」：报告呈现、只看做法、提取 Word、
复盘四步闭环（做法确认/模式草稿/四问/归档）全部可玩。

**所有企业、人名、数据、模式均为虚构演示内容，与任何真实公司无关。**
