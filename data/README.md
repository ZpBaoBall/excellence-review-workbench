# 99-数据 · 工作台账与字典（机器数据，非笔记）

本目录放**卓越绩效评审工作台**的两个机器数据文件，随知识库一起被 git 跟踪——换机器时整个 vault 文件夹拷走，数据不丢。

| 文件 | 内容 | 能否手改 |
|---|---|---|
| `ledger.json` | 项目台账（每条 = 一个评审项目的全部字段：id/企业/类别/阶段/结论/来源文件…） | 可以，但**优先用工作台界面改**；手改后存盘即可，工作台下次读取生效 |
| `dicts.json` | 三张字典表（区域 / 行业 GB/T 4754 / 类别）+ 模块登记 | 可加行（增删区域、行业、类别），格式照抄现有行；改坏会导致界面下拉异常，改前先复制一份 |

## 使用方式

- **日常**：不需要打开这个目录，启动工作台（`启动工作台.bat`）后在界面里操作即可。
- **换机器 / vault 挪位置**：把整个 vault 文件夹拷到新机器后，按《[[00-政府质量奖-换机迁移说明]]》（库根目录）改 config.yaml 里的绝对路径，数据文件本身不用动。
- **Obsidian 用户注意**：本目录的 .json 文件在 Obsidian 里看不到内容（Obsidian 只显示 md），这是正常的；要看台账请用工作台界面。

## 为什么在这里（而不在程序目录）

遵循「MD 是唯一真源、程序只是另一种看法」：报告正文、条款卡在 `10-条款与心得/`、`30-现场评审库/` 等目录，台账索引放在同一条业务线下（`99-数据/`），跟知识一起走。程序侧（`.工作台程序/`）只留代码、缓存和日志。
