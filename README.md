# 卓越绩效评审工作台

本地运行的单人评审工作台，围绕**政府质量奖**评审全流程：项目台账 → 文审报告提取与写入 → 现场评审条款核实 → 终版报告 → 复盘闭环（做法确认 → 模式草稿 → 四问 → 归档）。

- 后端：Python + FastAPI（单文件服务，零部署）
- 前端：原生 HTML/CSS/JS 免构建（`index.html + app.css + app.js`，本地内嵌，不依赖外网）
- 内容：评审报告/条款/模式全部是 **Obsidian vault 里的 Markdown**——MD 是唯一真源，平台只是快进快出的操作台
- 台账：程序内置 `data/ledger.json`（每次写入前自动备份）

## 功能一览

| 环节 | 说明 |
|------|------|
| 项目台账 | 新建/批量导入（xlsx·csv）/判重/筛选排序分页/按企业自动关联历史项目 |
| 文审 | 上传 Word → 结构化提取 → 条款归位（关键词猜+记忆）→ 写入文审报告 MD（程序节覆盖、手写节保留） |
| 现场评审 | 勾选「我负责的条款」（评分表缓存+横切项弹窗）→ 生成现场报告 → 分屏条款核实（左条款/右心得，宽度可拖拽记忆） |
| 终版+复盘 | 上传终版 Word → 写入 30 库现场 MD → 复盘四步闭环（做法确认/模式草稿/四问/归档，门禁=三步全留痕） |
| 统计图表 | 年份/类别/区域/行业/得分段/奖项 六图，口径跟随筛选 |
| 政策检索 | 生成检索任务包（outbox）→ 外部智能体联网检索 → 结果内联回填报告 |
| 脱敏 | 严格模式：出网必过闸必留痕；整篇报告生成**禁止出网**，只走任务包人工搬运 |

## 快速开始

```bash
pip install -r requirements.txt
# 复制配置模板并改成你的路径
cp config.example.yaml config.yaml
# 启动（Windows 直接双击 启动工作台.bat）
python app/main.py
```

浏览器打开 http://127.0.0.1:8765 。启动时控制台会打印 `[路径自检]`，8 项关键路径逐一核验，缺什么一目了然。

## 配置（config.yaml = 唯一事实来源）

- **程序段**：端口 / 数据目录 / 备份目录 / 交换区
- **vault 段**：你的 Obsidian 仓库根；评审报告、条款库、模式库都是 vault 里的 md
- **库.社会兼职.落点**：vault 下的子目录映射（可自定名字，自动创建）
- **模块段**：业务线开关。开通新模块三步——①「登记」里加一段（说明+奖项枚举）②加入「启用」列表 ③在 data/dicts.json 补该模块的类别行。台账/图表/下拉自动按模块过滤，无需改代码。预留模块在工作台模块条上**点名字可看规划说明**
- **脱敏段**：级别/规则/代号表/金额档位，改配置即时生效

换机迁移 = 拷走程序目录 + vault，改 config.yaml 里的路径（自检会兜底提示），测试无需改动（全部读配置）。

## 测试

```bash
# API 级自检（196 项，含台账守卫：备份→造→删净→md5 还原复核）
python test/selftest.py
# 浏览器级 E2E（101 项，playwright-core + Edge，需要 NODE_PATH 指向 node_modules）
node test/e2e.js
```

测试数据全部带「ST」标记，跑完自动删净并还原台账；样本 docx 由 `test/make_docx.py` 生成（企业名均为虚构示例）。

## 目录结构

```
app/main.py        FastAPI 全部路由（启动含路径自检）
app/store.py       台账/字典 JSON 存取（原子写+重试）
app/importer.py    新建/批量导入（判重：企业+年份+奖项）
app/review_writer.py  提取结果 → 评审报告 MD（程序节/手写节分离）
app/onsite_export.py  现场核实 → Word 导出
app/desens.py      脱敏闸+审计日志+备份轮转
app/static/        前端三件套 + 图表库（免构建）
test/              selftest.py / e2e.js / make_docx.py / fixtures
config.example.yaml  配置模板（注释即文档）
```

## 安全与脱敏（设计原则）

能不出网就不出网，出网必过闸、过闸必留痕。任何出网函数必须先调 `mask()`，不提供绕过参数；「整篇报告生成」被列为禁止出网场景。真实台账/报告/审计日志全部在 `.gitignore` 内，仓库不含任何业务数据。
